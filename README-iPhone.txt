マイメロ生活壁紙 iPhone用ホーム画面版

このブランチは既存Android版の main ブランチを変更せず、iPhone用起動ページとPWA設定を追加したものです。

公開後のURL:
  https://naochi1358-del.github.io/melody-wallpaper-v34/iphone.html

iPhoneへの追加:
1. Safariで上記URLを開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ

注意:
- iPhoneのホーム画面の壁紙そのものを動かすものではありません。ホーム画面アイコンから起動するWebアプリです。
- iOSのホーム画面追加では、PWAの一部機能やオフライン動作に制限があります。
- Pagesの公開設定はGitHub側で別途有効化が必要です。
- 既存のmainブランチ（Android向け）は変更していません。
